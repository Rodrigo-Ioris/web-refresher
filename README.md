
# Web Refresher

## Project Overview

This is a responsive student developer portfolio created using HTML5, CSS and JavaScript.

## Reflection

I found creating the HTML structure straightforward because semantic elements helped me organise the page into clear sections. I also enjoyed using CSS Grid to arrange the skill cards. One challenge was making the layout work correctly on smaller screens. I used media queries to adjust the number of columns for mobile devices. Adding skill icons made the website more visual and easier to understand. Implementing the dark mode button helped me practise JavaScript event listeners and DOM manipulation. During Web Development II, I would like to improve my JavaScript skills, especially form validation and creating more interactive features. I also want to become more confident using browser developer tools to identify and fix errors.
